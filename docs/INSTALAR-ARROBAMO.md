# Gracias por descargar ArrobAMO

## Windows 10/11 · 64 bits

**[Descargar ArrobAMOInstaller.exe](https://github.com/desarrollamo/ArrobAMO/releases/latest/download/ArrobAMOInstaller.exe)**

1. Abrí `ArrobAMOInstaller.exe` desde Descargas. No hace falta descomprimir archivos.
2. Leé y aceptá las condiciones; presioná **Instalar**. La instalación se hace para tu usuario de Windows, sin permisos de administrador.
3. Abrí ArrobAMO desde el Escritorio o el menú Inicio. Podés importar tus marcadores después.

El instalador incluye el navegador y sus bibliotecas. Si faltara **Microsoft WebView2 Runtime**, te indicará cómo descargarlo desde el sitio oficial de Microsoft. Para utilizar servicios de IA online necesitás conexión y tus propias cuentas.

**Actualizaciones:** descargá el nuevo instalador de esta misma página y ejecutalo con ArrobAMO cerrado. Tus marcadores, historial y ajustes se conservan en el perfil local. No hay actualización silenciosa.

**Seguridad:** el instalador todavía no está firmado digitalmente. Windows puede mostrar una advertencia al abrirlo. Comprobá que descargaste el archivo desde este repositorio oficial y consultá la suma SHA-256 de la publicación antes de ejecutarlo. No se debe ignorar una alerta de seguridad sin verificar su procedencia.

**Otra opción:** el [ZIP portátil](https://github.com/desarrollamo/ArrobAMO/releases/latest) está pensado para pruebas y usuarios que prefieren instalar manualmente. La opción habitual es el instalador EXE.

**Desinstalación:** Configuración de Windows → Aplicaciones → ArrobAMO → Desinstalar. Se eliminan los archivos del programa y se conservan los datos locales de navegación.
